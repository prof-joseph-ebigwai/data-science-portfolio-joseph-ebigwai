# E-News Express – A/B Testing and Statistical Analysis

## Project Overview

This project evaluates whether a redesigned landing page improves user engagement and conversion performance for E-News Express.

The analysis used an A/B testing framework to compare users exposed to the existing landing page with users exposed to a redesigned page.

## Business Questions

The project examined four main questions:

- Do users spend more time on the new landing page?
- Is the conversion rate higher for the new landing page?
- Is conversion associated with the user's preferred language?
- Does time spent on the new page differ across language groups?

## Dataset

The experiment included 100 users divided equally between:

- Control group – old landing page
- Treatment group – new landing page

The analysis considered:

- landing page version
- time spent on the page
- conversion outcome
- preferred language

## Statistical Methods

The following statistical techniques were applied:

- Independent t-test
- Two-proportion z-test
- Chi-square test of independence
- One-way ANOVA
- Descriptive statistics
- Data visualisation

## Key Findings

### Time Spent

Users spent significantly more time on the new landing page than on the old page.

Average time spent:

- New page: approximately 6.45 minutes
- Old page: approximately 4.31 minutes

### Conversion Rate

The redesigned page achieved a higher conversion rate.

- New landing page: 66%
- Old landing page: 42%

The two-proportion z-test produced a p-value of approximately 0.008, indicating a statistically significant improvement in conversion.

### Language and Conversion

The Chi-square analysis did not provide sufficient evidence that conversion depended on preferred language.

### Language and Engagement

The one-way ANOVA indicated that time spent on the new landing page differed significantly across language groups.

Spanish-speaking users showed higher engagement time than the English and French groups.

## Business Interpretation

The findings support adoption of the redesigned landing page while continuing to monitor engagement and conversion performance.

The project demonstrates how controlled experimentation and statistical hypothesis testing can replace intuition with evidence-based product decisions.
