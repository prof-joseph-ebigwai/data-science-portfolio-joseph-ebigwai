## Selected Projects

### 1. Loan Default Prediction

A machine-learning credit-risk project developed to identify borrowers at elevated risk of loan default or severe delinquency.

The project involved exploratory data analysis, statistical validation, preprocessing, feature engineering, class-imbalance treatment, model development, hyperparameter optimisation and independent test evaluation.

Models investigated included:

- Logistic Regression
- K-Nearest Neighbours
- Decision Tree
- Random Forest
- Gradient Boosting

The final solution used a tuned Gradient Boosting model with an operating threshold selected to support enhanced credit review rather than automatic loan rejection.

**Key areas demonstrated:**  
Python, Pandas, Scikit-learn, classification, model validation, imbalanced data, predictive analytics and business decision support.

---

### 2. EasyVisa – Visa Certification Prediction

A supervised machine-learning project examining factors associated with visa certification outcomes.

The project involved data preparation, exploratory analysis, predictive modelling and comparison of machine-learning approaches.

A tuned Random Forest model using oversampled training data was evaluated as a decision-support approach for identifying applications requiring closer review.

**Key areas demonstrated:**  
Python, EDA, classification, Random Forest, model evaluation, class-imbalance treatment and business interpretation.

---

### 3. E-News Express – A/B Testing and Business Analytics

A statistical and business analytics project evaluating user engagement and conversion behaviour associated with different website experiences.

The work involved exploratory analysis, hypothesis testing and interpretation of user behaviour to support evidence-based product and marketing decisions.

**Key areas demonstrated:**  
Statistical analysis, hypothesis testing, A/B testing, data visualisation and business analytics.

---

### 4. Retrieval-Augmented Generation for Medical Question Answering

An Artificial Intelligence and Natural Language Processing project exploring Retrieval-Augmented Generation (RAG) for medical information retrieval and question answering.

The project examined the use of an external medical knowledge source, language models, retrieval techniques and prompt engineering to improve the groundedness and relevance of generated responses.

The work included experimentation with language-model and retrieval configurations and evaluation of response quality.

**Key areas demonstrated:**  
Python, Natural Language Processing, Large Language Models, Retrieval-Augmented Generation, Hugging Face, prompt engineering and AI evaluation.

---

### 5. New Wheels – SQL Business Analysis

A database analytics project using SQL to analyse customer, sales and after-sales information for a vehicle resale business.

The analysis addressed management questions using database queries and translated query outputs into business insights.

**Key areas demonstrated:**  
SQL, relational databases, data querying, aggregation and business reporting.
